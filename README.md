# Jose Olan | Portfolio Personal

Un portafolio minimalista, moderno y enfocado en el producto. Creado para exhibir proyectos que cruzan la ingeniería de software con los datos y la talla artesanal de cada interfaz.

🌍 **Live Demo:** [jose_olan.dev](#) *(Actualiza esto con tu dominio cuando esté publicado)*

---

## 🛠 Tech Stack

El portafolio está construido utilizando tecnologías modernas para garantizar un rendimiento óptimo y una experiencia de usuario fluida:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Animaciones:** [Framer Motion](https://www.framer.com/motion/)

## ✨ Características

- **Diseño minimalista y editorial:** Centrado en la legibilidad y en la estructura visual inspirada en el diseño editorial.
- **Micro-interacciones:** Animaciones fluidas impulsadas por Framer Motion.
- **Narrativa de producto:** Secciones orientadas a demostrar soluciones a problemas reales (Servicios, Proyectos, Métricas).
- **Responsive:** Adaptable a todo tipo de pantallas (Mobile-first).

## 🚀 Correr localmente

Para clonar y ejecutar esta aplicación en tu máquina local:

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/tu-repo.git
```

2. Instala las dependencias:
```bash
npm install
# o
yarn install
# o
pnpm install
```

3. Inicia el servidor de desarrollo:
```bash
npm run dev
# o
yarn dev
# o
pnpm dev
```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

## 📂 Estructura del proyecto

- `/src/app` - Contiene la estructura de páginas y layouts (Next.js App Router).
- `/src/components` - Componentes reutilizables de UI (Hero, Navbar, Proyectos, etc).
- `/src/data` - Archivos de configuración y datos estáticos (`projects.ts`, `skills.ts`, `site.ts`).
- `/public` - Assets estáticos, imágenes, fuentes, etc.
